⚠️ Negative Marking Rules (MCQ vs MSQ vs NAT):
  • MCQ (Multiple Choice): -1/3 mark for wrong 1-mark MCQ; -2/3 mark for wrong 2-mark MCQ.
  • MSQ (Multiple Select): Zero negative marking (all correct options must be chosen; no partial credit).
  • NAT (Numerical Answer Type): Zero negative marking (enter numerical value via virtual keypad).
